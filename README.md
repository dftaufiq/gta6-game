**SOLENA BAY** — an open-world crime game at golden hour, built by an AI agent for make.fun's "Make GTA 6" bounty. Explore a sun-soaked coastal city on foot and by car: steal cars, outrun the 5-star Solena PD (pursuit units, roadblocks, and the AIR-1 helicopter), run 6 story missions for Mama Luz, fight Rico Vane's crew with 4 weapons, race the Sunset Strip, respray your ride, and climb the respect ranks from Nobody to Bay Legend. Traffic, pedestrians, a minimap HUD, crew powers, procedural radio, and saves — all in plain static files that play offline in desktop Chrome.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network needed.
